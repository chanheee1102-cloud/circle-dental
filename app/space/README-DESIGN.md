# /space 는 어두운 결 뒤집기에서 빠져 있다

2026-08-31. 서브페이지를 전부 어둡게 바꾸면서 이 폴더에만 `layout.tsx`(.page-dark)를 두지 않았다.

이유 두 가지 —

1. 이 페이지는 **밝은 띠와 어두운 띠를 번갈아 쓰는 자기 디자인**(`sp-*` 클래스)이다.
   위에서 색을 통째로 뒤집으면 밝은 띠 안의 어두운 글자가 사라진다(실측 6건).
2. **어디에서도 링크되지 않는다.** 주 메뉴·푸터·사이트맵 어디에도 없다.
   보이지 않는 화면을 맞추느라 보이는 화면을 위험에 빠뜨릴 이유가 없다.

살릴지 지울지는 운영자 판단 사항으로 남아 있다. 살리기로 하면 그때
`app/space/layout.tsx` 를 만들어 `.page-dark` 를 씌우고, 이 페이지의 밝은 띠들을
어두운 결로 다시 짜야 한다 — 색만 뒤집는 것으로는 안 된다.
